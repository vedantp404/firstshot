# firstshot
# Academic Course File Dashboard

A Streamlit dashboard for managing course outcomes, Program Outcomes (PO), and student learning attainment.

## Quick Start

### Installation
```bash
git clone https://github.com/vedantp404/firstshot.git
cd firstshot
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## Features

📚 **Course Management**
- Course Outcomes (CO) tracking
- Program Outcomes (PO) mapping
- Student attainment analysis

📊 **Analytics**
- Performance reports
- Learning outcome tracking
- Attainment vs target visualization

## Tech Stack
- Streamlit
- Python
- JSON

## Use Cases
✅ Course file documentation
